About

omarchylinux.org is a community hardware and switcher notebook for people who typed “Omarchy Linux” into a search box. The product, ISO, manual, plugins, themes, news, and Discord live at omarchy.org.

What this site is

  • Per-model compatibility notes compiled from official docs, GitHub, and public posts
  • Mac/Windows switcher checklists that point at the manual instead of rewriting it
  • A buying shortlist and an ISO verification reminder

What this site is not

  • An official download mirror
  • A theme or plugin store (use themes and plugins.omarchy.org)
  • A clone of the Omarchy homepage

Trademark

Omarchy is a pending trademark. We use the name only to talk about the distro. We do not use the official wordmark or logo. Partnerships: foundation@omarchy.org.

Send a hardware report

Include:

  • cat /sys/class/dmi/id/product_name and product_version
  • Omarchy version (omarchy --version or About)
  • Wi-Fi, audio, webcam, fingerprint, GPU, suspend: works / workaround / fails
  • Link to a GitHub issue if one exists

Open an issue on the site repo once it is public, or wait until a submit form exists. Do not email ISOs.
