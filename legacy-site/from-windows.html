From Windows

You can try before you wipe. You should, if this machine has to boot tomorrow.

Try first

  1. Try Omarchy for Windows — official QEMU app, no partition changes. ARM64 Windows (Snapdragon) is not supported.
  2. Fan-made browser demo: tryomarchy.dev (not affiliated; CPU-only, 15-minute sessions).

If you dual-boot

  • Official path: dual-boot install. Full-disk wipes the drive.
  • Turn off BitLocker and Windows Fast Startup first. Shrink from Windows, do not let a random YouTube video resize NTFS from Linux.
  • Disable Secure Boot / TPM as the installer asks. This is not a signed Microsoft distro.
  • Limine will show up in the firmware boot menu. That is the Omarchy bootloader. Auto-login after LUKS is intentional.

Games and Office

  • Steam + Proton is first-class. Battle.net, Lutris, Heroic, RetroArch, Moonlight ship in the gaming menu.
  • NVIDIA 50-series: installer may need nomodeset. See NVIDIA notes.
  • Windows 11 VM: Office and line-of-business apps. No GPU passthrough, so not a Fortnite box.
