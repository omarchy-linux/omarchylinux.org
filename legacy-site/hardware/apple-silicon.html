Apple Silicon and Snapdragon X

The public 4.0.3 ISO is x86_64. Native ARM is in flight (Omarchy M, aarch64 PRs). Taste-test with official Try Omarchy VMs instead of wiping.

Omarchy M (announced 11 Sep 2026)

Official team for Apple Silicon. First-release target is perfect M1 and M2 (including Pro/Max): installer with install + try, GPU, USB-C displays, Touch ID, MLX, encryption. M3 Air internal display recently went from unusable to usable via Apple’s hardware display controller. This is not “download the current ISO.”

Community Omarchy Mac already runs on M1/M2 with elbow grease (Discord ~800). Try Omarchy for macOS is the supported VM path today.
