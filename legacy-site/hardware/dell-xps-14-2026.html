Dell XPS 14 / 16 (2026, Panther Lake)

If you are buying a new laptop for Omarchy, this is the one the project actually co-developed. Dell published a “Year of the Linux Laptop” post; Omarchy Core includes Dell engineer Spencer Bull.

Status
Day-one enablement in Omarchy 3.5+
Kernel
Custom linux-ptl until mainline has the backports
Wi-Fi 7
Patched
Trackpad
Haptic package dell-xps-touchpad-haptics
Camera
IPU7 via intel-ipu7-camera
Speakers
Tuned; XPS 13 DX13260 has a sidecar-amp quirk package

What still bites

  • Older XPS (e.g. 7590) with Goodix fingerprint readers often detect the sensor and still cannot enroll. That is a libfprint gap, not Omarchy-specific.
  • If haptics die after sleep, official menu path is Update → Hardware → Trackpad.
