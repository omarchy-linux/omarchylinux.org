Steam Deck

Official Omarchy is an x86_64 desktop ISO, not a Deck image. A community project (Pizzarchy) builds a controller-only installer that keeps Gaming Mode and puts Omarchy on the desktop side, using Valve’s Neptune kernel.

That image is not from omarchy.org. If you try it, verify the checksum yourself and know that going back means Valve’s recovery image. We will not mirror it.
