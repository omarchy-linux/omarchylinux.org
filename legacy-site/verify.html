Verify the ISO

Omarchy 4.0.1 patched a real privilege issue (user in the docker group). Do not add a second supply-chain problem by grabbing an image from a random mirror.

  1. Get the file from the official installer block: omarchy.org/#install
  2. Current image at time of writing: iso.omarchy.org/omarchy-4.0.3.iso
  3. Download the matching .sha256 and .sig into the same folder.
sha256sum -c omarchy-4.0.3.iso.sha256

Then check the signature against the Omarchy signing key from the official docs. If either check fails, delete the file. Do not “just try it.”

Flash with balenaEtcher (Mac/Windows) or caligula (Linux). Official walkthrough: Getting Started.
