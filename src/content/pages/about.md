## What this is

An unofficial field manual for [Omarchy](https://omarchy.org), the Arch Linux and Hyprland distribution created by David Heinemeier Hansson and now stewarded by the Omacom Foundation. The official site has the manual, the installer, the plugin and theme marketplaces, and the news. This site covers what the official site does not: per-machine hardware reports, one page per error with the fix at the top, a generated reference for every command and keybinding, and a plain-language account of what each release changed.

- **Not the manual.** When this site and the [official manual](https://omarchy.org/manual/) disagree, the manual wins for the version it describes. We link it everywhere.

## How pages are verified

Every page carries an "applies to" version range and a "last verified" date. Fix pages are written from the GitHub issue or discussion where the fix was found, credit the person who found it, and link the original thread. We paraphrase rather than copy, because issue comments on GitHub are not licensed for republication. Reference pages are generated by scripts from the MIT-licensed source at each release tag, so a command that was removed in a release shows as removed. Hardware pages combine issue-tracker data with reports people submit.

When a fix stops working on a newer version, the page is updated or marked. If you find a stale page, use "Improve this page" at the bottom of it.

## Who runs it

An independent Omarchy user. The site's source, data pipeline, and content are public on GitHub so anyone can check the work. If the Omacom Foundation would prefer to hold the domain, it is theirs on request. If a page here is wrong or misrepresents the project, email hello@omarchylinux.org and it will be fixed.
